# Entrega 1 · Definições do projeto

**Semana 1 do Challenge 2.** Foco: problema, stakeholders, riscos e métricas.

!!! abstract "Resumo"
    O estudante do campus Gama toma, toda semana, decisões sobre **alimentação** (RU) e sobre **percurso acadêmico** (disciplinas, pré-requisitos, matrícula). As regras que orientam essas decisões são públicas, mas estão espalhadas em dezenas de documentos difíceis de consultar. O RUmo propõe um assistente com RAG que responde com base nesses documentos, cita a fonte de cada afirmação e recusa o que não está na base.

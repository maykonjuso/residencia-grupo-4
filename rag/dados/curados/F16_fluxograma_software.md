# Fluxograma do curso de Engenharia de Software — FCTE/UnB (campus Gama)

Fonte: imagem oficial "Fluxograma – Engenharia Software" publicada em https://software.unb.br/matriz-curricular/ (arquivo grade_curricular_esw.jpg, fev/2026). Transcrição feita pelo Grupo 04 em 06/11/2026. Vale para quem ingressou após 2024/2 (total de 235 créditos). A lista oficial de pré-requisitos de cada disciplina é a do SIGAA; as relações abaixo foram lidas das setas do fluxograma.

Os quatro números de cada disciplina são: créditos teóricos, créditos práticos, créditos de extensão e total de créditos (T-P-E-Total). Cada crédito equivale a 15 horas. Disciplinas em amarelo no fluxograma são comuns às cinco engenharias da FCTE; em verde, específicas de Software; em laranja, TCC e Projeto Integrador; em magenta, optativas.

## Pré-requisitos de cada disciplina de Engenharia de Software (lidos das setas do fluxograma)
Seta cheia = pré-requisito indicado no fluxograma. Seta tracejada = ligação indicada de forma tracejada no fluxograma (confirmar no SIGAA se é pré-requisito ou correquisito).
- Para cursar Cálculo 2 (MAT0026), é preciso ter cursado antes: Cálculo 1 (MAT0025).
- Para cursar Métodos Numéricos para Engenharia (FGA0160), é preciso ter cursado antes: Cálculo 2 (MAT0026).
- Para cursar Gestão da Produção e Qualidade (FGA0307), é preciso ter cursado antes: Engenharia Econômica (FGA0133).
- Para cursar Orientação a Objetos (FGA0158), é preciso ter cursado antes: Algoritmos e Programação de Computadores (CIC0004).
- Para cursar Estruturas de Dados 1 (FGA0146), é preciso ter cursado antes: Algoritmos e Programação de Computadores (CIC0004).
- Para cursar Métodos de Desenvolvimento de Software (FGA0312), é preciso ter cursado antes: Orientação a Objetos (FGA0158).
- Para cursar Requisitos de Software (FGA0313), é preciso ter cursado antes: Métodos de Desenvolvimento de Software (FGA0312).
- Para cursar Testes de Software (FGA0314), é preciso ter cursado antes: Requisitos de Software (FGA0313) (seta cheia); o fluxograma também liga Métodos de Desenvolvimento de Software (FGA0312) a Testes de Software por seta tracejada.
- Para cursar Gerência de Configuração e Evolução de Software (FGA0317), é preciso ter cursado antes: Testes de Software (FGA0314).
- Para cursar Engenharia de Produto de Software (FGA0316), é preciso ter cursado antes: Técnicas de Programação em Plataformas Emergentes (FGA0242).
- Para cursar Estruturas de Dados 2 (FGA0030), é preciso ter cursado antes: Estruturas de Dados 1 (FGA0146).
- Para cursar Projeto e Análise de Algoritmos (FGA0124), é preciso ter cursado antes: Estruturas de Dados 2 (FGA0030).
- Prática de Eletrônica Digital 1 (FGA0071) é correquisito de Teoria de Eletrônica Digital 1 (FGA0073): as duas são cursadas no mesmo semestre.
- Para cursar Fundamentos de Arquiteturas de Computadores (FGA0142), é preciso ter cursado antes: Teoria de Eletrônica Digital 1 (FGA0073).
- Para cursar Fundamentos de Sistemas Operacionais (FGA0170), é preciso ter cursado antes: Fundamentos de Arquiteturas de Computadores (FGA0142).
- Para cursar Fundamentos de Redes de Computadores (FGA0211), é preciso ter cursado antes: Fundamentos de Sistemas Operacionais (FGA0170).
- Para cursar Programação para Sistemas Paralelos e Distribuídos (FGA0244), é preciso ter cursado antes: Fundamentos de Redes de Computadores (FGA0211).
- Para cursar Sistemas de Banco de Dados 2 (FGA0060), é preciso ter cursado antes: Sistemas de Banco de Dados 1 (FGA0137).
- Para cursar Matemática Discreta 2 (FGA0108), é preciso ter cursado antes: Matemática Discreta 1 (FGA0085).
- Para cursar Projeto Integrador de Engenharia 2 (FGA0304), é preciso ter cursado antes: Projeto Integrador de Engenharia 1 (FGA0303).
- Para cursar Trabalho de Conclusão de Curso 2 (FGA0290), é preciso ter cursado antes: Trabalho de Conclusão de Curso 1 (FGA0287).

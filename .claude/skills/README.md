# Skills do repositório

Skills de uso geral, reaproveitadas do Challenge 1 (Senhora Vera). São de **terceiros**:
cada uma veio de um repositório público do GitHub e mantém a licença original. A
procedência e o hash de cada arquivo estão em [`skills-lock.json`](skills-lock.json).

| Skill | Para que serve aqui | Origem |
| --- | --- | --- |
| `frontend-design` | Interface e GitPage: hierarquia visual, espaçamento, estados | `anthropics/skills` (Apache 2.0) |
| `animation-vocabulary` | Diagramas animados do RUmo (`docs/javascripts/rumo.js`) | `emilkowalski/skills` |
| `brandkit` | Identidade visual da UnB, comum com o Grupo 09 (RNF05) | `leonxlnx/taste-skill` |
| `extract-design-system` | Extrair tokens de cor e tipografia de páginas da UnB | `arvindrk/extract-design-system` |
| `agent-browser` | Navegar e conferir páginas oficiais durante a coleta de fontes | `vercel-labs/agent-browser` |
| `find-skills` | Localizar skills para uma tarefa | `vercel-labs/skills` |
| `monorepo-management` | Conviver `docs/` e `rag/` no mesmo repositório | `wshobson/agents` |

As skills específicas do produto anterior (`vera-*`) **não** foram trazidas: tratavam dos
sinais, camadas e persona da Senhora Vera, que não existem no RUmo. O equivalente do
RUmo — convenções de issue, branch, PR, DoR e DoD — é documentado neste repositório.
